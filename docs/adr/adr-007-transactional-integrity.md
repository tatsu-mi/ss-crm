# ADR 007 DBトランザクションと競合制御で保存時の整合性を保証する

## ステータス

採用

## 決定日

2026-10-16

## コンテキスト

記録の値・参照・履歴を部分的に保存したり、同時操作で契約期間や1件限定の制約を破ったりすることを防ぐ必要がある。

## 検討した選択肢

元資料に比較の履歴はない。以下は採用済みの保証方式と、その保証を満たさない方式の整理である。

採用：DBでの検証、同一トランザクション、版番号と書き込みロックによる競合制御。

不採用：アプリケーションでの事前チェックだけに依存する。

不採用：値・参照・履歴を独立して保存する。

## 決定事項

業務上の制約をDBの保存境界で検証する。記録の値・参照・変更履歴は同一トランザクションで保存する。版番号で同時編集を検出する。競合する書き込みをロックで制御し、同時保存でも契約期間の重複防止と1件限定の制約を保証する。

## 決定理由

保存境界で検証と排他制御を行うことで、複数の利用者が同時に操作しても部分保存と制約違反を防げるため。

## 結果

履歴を含む一貫した保存を保証できる。一方、排他制御は書き込み並列性を制限する。ロックの粒度を変更する場合も、同時操作に対する保証を維持する必要がある。
