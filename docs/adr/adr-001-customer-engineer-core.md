# ADR 001 顧客・エンジニア・参画関係を固定の中心とする

## ステータス

採用

## 決定日

2026-10-16

## コンテキスト

SES営業では顧客とエンジニア、および両者の提案・参画の接点が情報管理の中心になる。顧客起点とエンジニア起点の双方から同じ情報を扱う必要がある。

## 検討した選択肢

採用：顧客・エンジニア・両者の関係を固定エンティティとする。

不採用：中心の関係も自由な記録だけで表す。関係の識別と整合性が不明確になる。

## 決定事項

顧客、エンジニア、顧客とエンジニアの関係を固定の業務エンティティとする。関係は一連の提案・参画の接点を表し、同じ組み合わせに複数作成できる。中心の識別と関係を固定し、業務ごとに変わる追加属性は[定義付きの記録](adr-002-extensible-records.md)に分離する。

## 決定理由

関係の識別を安定させながら、業務ごとに異なる追加属性を拡張できるため。

## 結果

同じ顧客とエンジニアの複数の接点を区別でき、双方を起点とする画面で情報を共有できる。中心の属性と追加属性の責務を分けて管理する必要がある。
