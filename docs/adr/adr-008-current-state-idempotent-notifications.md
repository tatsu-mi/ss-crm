# ADR 008 最新状態から冪等なアプリ内通知を生成する

## ステータス

採用

## 決定日

2026-10-16

## コンテキスト

期限・担当・状態が変更されても適切に通知し、定期処理の再実行で通知や更新確認タスクが重複しないようにする必要がある。

## 検討した選択肢

採用：定期処理で最新状態から通知の要否を判定し、通知機会のキーで重複を防ぐ。

不採用：将来の通知予定を事前にキューへ積む。予定変更への追従と取消の管理が必要になる。

## 決定事項

最新の期限・担当・状態に基づき、その時点で必要なアプリ内通知を生成する。通知は対象・担当・ルール・期限で定める通知機会ごとに一意とし、条件変更後は新しい通知機会として扱う。更新確認タスクは契約期間ごとに一意とする。配信済み・既読の通知は保持する。通知対象から外れた記録は再通知しない。

## 決定理由

最新状態を基準にすることで予定変更への追従を簡潔にし、安定したキーによって再実行時の重複を防げるため。

## 結果

更新確認と通知の重複を防ぎ、通知履歴を残せる。判定は定期処理の時点に依存するため、状態変更直後の即時通知は保証しない。
