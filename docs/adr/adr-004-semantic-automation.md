# ADR 004 自動処理を項目と選択肢の意味に結び付ける

## ステータス

採用

## 決定日

2026-10-16

## コンテキスト

通知や状態判定には値の業務上の意味が必要だが、表示名は利用者が変更できる。

## 検討した選択肢

採用：情報種別の利用機能と、項目の役割・選択肢の意味に基づく自動処理。

不採用：表示名から業務上の意味を推測する。名称変更で動作が不安定になる。

## 決定事項

自動処理は情報種別が利用する機能と項目の役割を使う。自動処理が読む項目と選択肢には、表示名とは独立した業務上の意味を持たせる。表示名の変更は意味を変えない。通常の追加項目では役割を必須としないが、自動処理の対象には必要な役割・型・制約を求める。

## 決定理由

表示のカスタマイズから業務上の意味を独立させ、名称変更後も自動処理を維持できるため。

## 結果

項目追加だけでは自動的に通知対象にはならない。新しい種類の自動処理にはシステム側の機能実装が必要になる。
