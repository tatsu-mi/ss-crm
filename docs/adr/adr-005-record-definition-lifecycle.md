# ADR 005 記録の論理削除と定義の利用停止で過去の情報を守る

## ステータス

採用

## 決定日

2026-10-16

## コンテキスト

不要な情報を整理しても、過去の記録・履歴・自動処理が依存する意味を失わないようにする必要がある。

## 検討した選択肢

採用：記録の論理削除・復元と、定義の利用停止を区別する。

不採用：記録と使用済み定義を物理削除する。過去の値とその意味を失う。

## 決定事項

記録の削除は論理削除とし、通常の表示・通知から除外して復元可能とする。情報種別・項目・選択肢の利用停止は新規入力を止め、過去の値・履歴・意味を保持する。使用済み項目のキー・型は変更せず、型変更は新しい項目への明示的な移行とする。定義変更によって依存する自動処理の意味を暗黙に変えず、移行または機能停止を明示する。顧客・エンジニア・関係の保管で関連記録を連鎖削除しない。

## 決定理由

情報整理と過去の情報の保全を両立し、定義変更による履歴の破損や自動処理の意図しない変化を防ぐため。

## 結果

過去の情報を参照し続けられる。一方、削除・停止・保管を区別する表示と依存関係の管理が必要になる。
